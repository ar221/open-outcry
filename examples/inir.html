A desktop shell that behaves like a mission console.

iNiR is a Quickshell shell for the niri Wayland compositor. Bar, dock, overview, sidebars, lock, command room — one process, one design grammar, every surface answerable over IPC.

GOVERNING TEST — would I feel proud showing this to another nerd?

// 01 · WHAT IT IS
MATERIAL YOU PIPELINE

One wallpaper seeds the whole palette.

matugen extracts tones from the image; panels, terminals, and widgets re-ink themselves live. Change the picture, the shell follows.

NIRI-NATIVE

Built against the compositor, not ported to it.

Workspaces, overview, and keybinds speak niri's own event stream. Scrollable tiling is the assumption, not an afterthought.

COURIER CONSOLE GRAMMAR

Command surfaces follow a fixed grammar.

Dispatch boards, square hardware, receipt-backed status cards. Density with breathable whitespace — flight deck, not dashboard.

// 02 · THE MACHINE, QUOTED

Every surface is an IPC target. The same call works from a terminal, a script, or a niri keybind — taken verbatim from the repo's docs/IPC.md:

$ inir overview toggle
# the same target, bound in niri config (kdl):
bind "Mod+Space" { spawn "inir" "overview" "toggle"; }
