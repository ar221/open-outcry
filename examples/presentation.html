// 02 · argument

Two ways to attach evidence. They answer different questions.

  1. Resolve at read time — the note always shows current state. It answers what is true now.

  2. Freeze at publication — the note shows the state it was written against. It answers what was true then.

  3. A note is a dated claim, so only the second is answerable. Give it read-time provenance and the evidence moves underneath the conclusion with no record of the move.

// 04 · cost and alternatives

Freezing does not prevent staleness. It declares it.

THE COST

A snapshot stops reporting current state when its source changes. Keep its date legible and retain older editions. No crawl, live dot or cursor: this is a dated claim.

A · Resolve at read time. Right for mirrors, wrong question for a dated note.

Rejected

B · Frozen block plus live badge. Two owners for one fact; fails offline as if the note were wrong.

Rejected

C · No provenance block. Cheapest, and every claim becomes uncheckable.

Rejected

D · Freeze · one owner · re-issue. A locatable citation, bought with declared staleness.

Chosen

// 05 · conclusion

Freeze it, own it once, re-issue it.

  1. A note's provenance block is content. Review it with the prose.

  2. A version label printed twice is a defect, whichever copy is right.

  3. A document that says it is frozen has to look frozen.
