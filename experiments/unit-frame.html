UNIT & FRAME. UNIT & FRAME.

Four mechanisms extracted from the Nous Portal on 2026-08-08 with designlang 12.15.0 — 579 custom properties on its root — and re-expressed in Console. None of its surface comes with them: that site is #0000f2 with 9999px pills, which is the spec's stated hard dislike list almost verbatim. Only the machinery crosses over. Every candidate here is page-local under --lab6-*; tokens.css v1.3 and components.css v1.5 are untouched.

A · ONE UNIT DRIVES EVERY DIMENSION

--lab6-u: max(calc(100cqw / 1440), 0.58px). Author in artboard pixels — calc(28 * var(--lab6-u)) is literally 28px at a 1440px container and scales proportionally everywhere else. Container-relative, so it works inside a pane, not only against the window. Resize this page: the title, the body, the padding and the bars below all move on one number. The current contract moves none of them together.

SCALES AS ONE OBJECT.
Padding 28×32, title 44, body 20, gap 20, bars 40/64/88/120 — every value here is the number a designer would write on a 1440 artboard, multiplied by the unit. No clamp, no breakpoint, no constant tuned by eye. The two type sizes additionally carry an absolute rem backstop, because the unit alone will happily compute 11px body copy.
contract now — independent clamps
--oo-display-console: clamp(36px, 7vw, 112px); .oo-plate { padding: 88px 0 } .oo-specimen { padding: 48px } .oo-stat { padding: 24px 28px } .oo-grid-* { gap: 16px } /* 7vw reads the WINDOW. On a 2560px monitor the display pins to its 112px ceiling while the plate stays 1080px — the headline stops relating to the plate it sits on. Spacing is five unrelated constants; the scale has been deferred since v1.3. */
candidate — one scalar, three floors
--lab6-u-anchor: 0.58px; --lab6-u: max(calc(100cqw / 1440), var(--lab6-u-anchor)); --lab6-u-text: max(var(--lab6-u), 0.62px); @media (max-width: 720px) { --lab6-u: min(calc(100cqw / 460), calc(1.2 * var(--lab6-u-anchor))); } /* per-role absolute backstop, and it is NOT optional — the first pass omitted it and body copy computed to 11.1px: */ font-size: max(calc(20 * var(--lab6-u-text)), .875rem); /* Chrome floors, then text floors higher, then the rem floor catches both. Narrow flips to a 460 artboard, capped, so a phone gets a phone layout instead of a shrunken desk. */

C · THE MASTHEAD FITS ITS MEASURE

tan(atan2(available, available − captured)) evaluates to available ÷ captured — CSS has no length division, and this is it. The headline is scaled to exactly fill its container, with no JS and no resize observer. Three mastheads, three different character counts, one identical rule. A clamp() cannot do this, because the correct size depends on the string.

Each string appears twice in the DOM. The second copy is aria-hidden and visibility: hidden: it is the measuring ruler, and it exists because an element carrying container-type is forbidden by containment from measuring its own contents. The technique measures the leftover space beside the copy and subtracts.

D · SEATED SEMANTICS & SELECTION INK

color-mix(in srgb, var(--oo-green) 18%, var(--oo-console-stage)). The market tokens are tuned as ink on the stage and are right there; as fills they are neon slabs that break the void law. Mixing the existing token into the surface gives a fill ramp without making a new colour decision. VERDICT

B and D1 are drop-in and reversible — one token and one two-line rule, no new naming authority, no layout consequences. C is the highest-value and lowest-risk of the three big ones: it is additive, opt-in per element, and it answers a spec requirement ("short phrases" mastheads) the current contract cannot meet. A is the one that is genuinely worth arguing about — it is a second sizing philosophy sitting beside the existing one, which is exactly how a design system quietly becomes a layout framework. It should not be promoted on the strength of one lab. Reasoning and the evidence each candidate still owes: UNIT-FRAME-RECEIPT.md.
